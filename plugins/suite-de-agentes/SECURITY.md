# Security Policy

## Supported Versions

We actively provide security updates for the current major release line:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Suite de Agentes seriously. If you discover or suspect a security vulnerability, please report it responsibly.

### How to Report

- **Preferred Method**: Submit a private vulnerability report via [GitHub Security Advisories](https://github.com/RamonsDka/suite-de-agentes/security/advisories/new).
- **Public Disclosures**: Please **do NOT** open public GitHub issues, discussions, or pull requests for suspected security vulnerabilities.
- **No Secrets**: Never include active API tokens, private authentication cookies, or confidential credentials in your reports.

### What to Include in Your Report

To help us investigate efficiently, please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction steps or a minimal proof of concept (PoC).
- Affected version(s) and environment details (Node.js, OS, OpenCode version).

### Response Expectations

- **Triage & Assessment**: Reports are reviewed by maintainers on a best-effort basis as time permits. We do not guarantee a fixed SLA or turnaround time, but we prioritize verifiable security issues.
- **Coordination**: We will coordinate with you to validate the vulnerability, develop a fix, and agree on a responsible disclosure timeline before releasing a patch.
