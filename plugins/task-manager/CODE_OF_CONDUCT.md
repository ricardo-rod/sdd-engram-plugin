# Código de conducta

## Nuestro compromiso

Nos comprometemos a mantener una comunidad respetuosa, inclusiva y orientada al aprendizaje para todas las personas, independientemente de su experiencia o identidad.

## Comportamiento esperado

- Comunicar desacuerdos con argumentos técnicos y respeto.
- Dar feedback específico, accionable y centrado en el trabajo.
- Reconocer errores y corregirlos con evidencia.
- Ayudar a personas nuevas a comprender el proyecto.
- Evitar acoso, discriminación, ataques personales y divulgación de información privada.

## Aplicación

El mantenimiento puede editar, ocultar o eliminar contribuciones que incumplan estas reglas y limitar la participación cuando sea necesario.

Para informar un incidente, utiliza un canal privado del mantenedor o GitHub Security Advisories cuando corresponda.
